# NoAds для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa), который убирает рекламу.

## Что делает

1. **Сеть** — блокирует загрузку рекламного инвентаря CUB и запросы к известным рекламным сетям (XHR + fetch).
2. **Плеер** — вычищает `vast_url` / preroll-поля и глушит модуль Preroll.
3. **DOM** — если рекламный ролик всё же запустился, глушит звук, перематывает и жмёт «Пропустить»; скрывает баннеры и промо-блоки.
4. **Жёсткий режим** (опционально) — заставляет Lampa считать запуск безрекламным на этапе проверки пререлла.

Код на ES5, работает на старых webOS / Tizen.

## Установка

Настройки → Расширения → Добавить плагин → вставьте URL:

```
https://raw.githubusercontent.com/y92487046-boop/LAMPA_noads/main/noads.js
```

## Настройки

Хранятся в `Lampa.Storage`: `noads_enabled` (по умолчанию `true`) и `noads_hard` (по умолчанию `false`).
